# WORK WATCH — руководство пользователя

**WORK WATCH** — веб-приложение для ведения графика работ на объектах, оперативной сводки по сменам и отпускам, расстановки инженеров по зонам и просмотра карты BLE-меток на территории.

Сайт работает в браузере без установки программ. Адрес публикации: [https://its-helper.github.io/tabel/](https://its-helper.github.io/tabel/).

В приложении две основные части:

1. **График работ (табель)** — главная страница.
2. **Карта BLE-меток** — открывается кнопкой **«Карта»** в шапке; на телефоне может открываться на весь экран.

## 1. Первый запуск

1. Откройте сайт в браузере (Chrome, Edge, Safari и т.д.).
2. По умолчанию отображается **текущий календарный месяц** и вкладка объекта **«Усть-Луга»**.
3. Блоки **Сводка**, **Расстановка по зонам**, **Отпуска** и **Объекты** по умолчанию **свёрнуты** — нажмите на заголовок панели, чтобы развернуть.
4. График внизу страницы всегда виден; при открытии месяца, совпадающего с текущим календарным, таблица **прокручивается к столбцу «сегодня»**.

Без входа в систему доступен **только просмотр**. Чтобы править график, расстановку и настройки — нажмите **«Войти»** (см. раздел [Вход и права](#3-вход-и-права)).

## 2. Шапка и навигация

### Логотип и заголовок

Слева — логотип **WORK WATCH by ITS** и подпись **«График работ»** с годом табеля (год берётся из выбранного месяца).

### Кнопки справа

| Кнопка | Назначение |
|--------|------------|
| **Карта** | Переход на карту BLE-меток |
| Иконка луны | Переключение **светлой / тёмной** темы (настройка не сохраняется — при следующем открытии снова светлая тема) |
| **Войти** / имя | Меню входа и действий после авторизации |

### Нижняя строка шапки

- **Бейдж «N сотр.»** — число сотрудников на экране с учётом выбранного объекта и фильтров.
- **Вкладки объектов** — переключение между **Усть-Луга**, **Пилотные проекты** и **Сводная** (если включена).
- **Селектор месяца** — выбор периода графика (см. [Архив месяцев](#13-архив-месяцев)).

## 3. Вход и права

### Как войти

1. Нажмите **«Войти»** в шапке.
2. Введите **логин** и **пароль**, нажмите **«Войти»**.
3. После успешного входа кнопка покажет **«Админ»** или **имя** (фамилия сотрудника). Откроется меню с дополнительными пунктами.

Отдельного переключателя «Просмотр / Редактирование» нет: после входа приложение само включает режим правок **в пределах вашей роли**.

### Роли и что можно менять

| Роль | График (ячейки) | Расстановка по зонам | Объекты и состав | Экспорт |
|------|-----------------|----------------------|------------------|---------|
| **Без входа** | Только просмотр | Только просмотр | Недоступно | Недоступен |
| **Администратор** | Все строки, все «живые» месяцы | Да | Да | Да |
| **Сотрудник (Пилотные проекты)** | Только **своя** строка | Да (если не архив) | Нет | Да |
| **Сотрудник (Усть-Луга)** | Только просмотр графика | Да (если не архив) | Нет | Да |

**Живые месяцы** — три календарных периода: **предыдущий**, **текущий** и **следующий** месяц относительно сегодняшней даты. В архивных месяцах правки недоступны никому.

### Меню после входа

Нажмите на имя / **«Админ»**:

- **Экспорт для 1С** — выгрузка JSON по открытому месяцу.
- **Объекты и состав** — только у администратора.
- **Сменить пароль** — смена пароля текущего пользователя.
- **Выйти** — завершение сессии.

Сессия хранится в браузере до закрытия вкладки (около 12 часов). На другом устройстве нужно войти снова.

### Смена пароля

1. Меню → **Сменить пароль**.
2. Укажите текущий и новый пароль (не короче 8 символов, не допускается пароль `12345678`).
3. **Сохранить**.

При первом входе с временным паролем система может потребовать смену пароля до работы с табелем.

## 4. Объекты и месяцы

### Вкладки объектов

- **Усть-Луга** — основной объект; в графике преобладают коды **СПГ** / **СПГ.** (день и ночь на ВСМ).
- **Пилотные проекты** — отдельная команда; часть сотрудников по умолчанию отнесена сюда (список настраивает администратор).
- **Сводная** — сводный вид (если используется в вашей установке).

Сводка «на сегодня / завтра», расстановка и фильтр табеля учитывают **текущую вкладку**.

### Выбор месяца

В селекторе месяца:

1. **Верхняя группа** — три **«живых»** месяца (прошлый, текущий, следующий). Их можно **редактировать** после входа (по роли).
2. **Группа «Архив»** — прошедшие месяцы текущего года **с марта** и данные прошлых лет (если загружены в систему). Только **просмотр**.
3. **«Остаток года (пусто)»** — будущие месяцы года вне окна «живых»: график **пустой** до наступления месяца.

Год в заголовке (**«График работ 2026»**) соответствует году выбранного месяца, а не обязательно системному году на компьютере.

## 5. Сводка

Панель **«Сводка»** показывает оперативную картину по **текущей вкладке объекта**.

Данные считаются по **реальным календарным** «сегодня» и «завтра», а коды смен берутся из графика **года, выбранного в селекторе месяца** (в подписи указано: «по графику 20XX г.»).

### Сегодня

- **День / Ночь** — число сотрудников на смене (дневные коды объектов и ночная смена **СПГ.**).
- **Выходной (ВХ)** — кто сегодня с кодом ВХ.
- **Болеют (Б / БЛ)** — больничные.

### Завтра

- **Выходной (ВХ)** — кто завтра на выходном.
- **Первый день отпуска (ВП / ОТ)** — у кого завтра начинается отпускная цепочка (см. [Отпуска](#8-отпуска)).

Если в месяце нет данных графика, сводка сообщит об этом.

## 6. Расстановка по зонам

Блок **«Расстановка по зонам»** — планирование размещения инженеров по площадкам на **выбранный месяц** и **текущий объект** (Усть-Луга или Пилоты).

### Зоны

| Зона | Назначение |
|------|------------|
| **СПГ 1 … СПГ 3.1** | Участки объекта |
| **Усиление** | Дополнительное усиление |
| **Выходной** | Сотрудники с выходным **сегодня** (по коду ВХ в графике на сегодняшнюю дату) |
| **Нераспределённые** | Ещё не назначены в зоны |

В расстановку попадают сотрудники **текущей вкладки**, у которых в месяце есть **хотя бы одна смена на объекте**; сотрудники только с отпуском/офисом без смен в пул обычно не попадают.

### Утро и вечер

Переключатель **«Утро» / «Вечер»** — отдельная расстановка на каждую смену дня. Данные сохраняются для обоих вариантов.

### Как распределить

1. **Перетащите** фишку сотрудника в нужную зону.
2. Или **кликните** сотрудника, затем кликните зону (на мобильном удобен второй способ).
3. На мобильном при перетаскивании может открыться **нижняя панель** с крупными кнопками зон.

### Дополнительные кнопки

- **Копировать расстановку** — скопировать текущую схему (например, с утра на вечер — уточняйте по подсказке на экране).
- **Сбросить** — вернуть автоматическое распределение (нерспределённые + выходные по ВХ на сегодня).

Правки доступны после входа (не в архиве). Изменения **синхронизируются** между устройствами вместе с остальными общими данными табеля.

## 7. Объекты (фильтр легенды)

Панель **«Объекты»** — это **фильтр табеля по кодам смен**, а не список строительных объектов на карте.

### Как фильтровать

1. Разверните панель **«Объекты»**.
2. Нажмите на один или несколько **цветных бейджей** с кодами (СПГ, ОТ, ВХ и т.д.).
3. В таблице останутся сотрудники, у которых в **выбранном месяце** есть **хотя бы один день** с любым из отмеченных кодов.
4. Повторное нажатие снимает код с фильтра.
5. **«Снять выбор отметок»** — очистить все выбранные коды.

### «Показать всех»

По умолчанию в табеле **скрыты** сотрудники без смен на объектах в этом месяце (только отпуск, офис, выходные без выезда и т.п.).

Кнопка **«Показать всех»** добавляет таких людей в список. Повторное нажатие (**«Только со сменами»**) возвращает прежний режим.

Фильтр легенды и флаг «показать всех» **сохраняются на сервере** и видны на других устройствах. Выбранные коды фильтра **не** синхронизируются — они только в вашем браузере до перезагрузки.

## 8. Отпуска

Панель **«Отпуска»** для **открытого в селекторе месяца**:

### Уезжают в отпуск

Сотрудники, у которых в этом месяце **начинается** отпускная цепочка:

- первый и последний день отпуска часто отмечаются **ВП** (в пути);
- дни между — **ОТ** (отпуск);
- если в графике только **ОТ** без **ВП**, учитывается только блок **ОТ**.

Если отпуск начался в прошлом месяце, в карточке могут показаться **полные даты** всего отпуска и его длительность.

### Возвращаются с отпуска

Первый рабочий день **после** цепочки ВП/ОТ, если он попадает в открытый месяц.

## 9. График смен

Основная таблица внизу страницы.

### Закреплённые столбцы

Слева (при прокрутке остаются на месте):

| Столбец | Содержимое |
|---------|------------|
| **ТН** | Табельный номер |
| **ФИО** | Фамилия и имя |
| **Должность** | Должность |
| **Дни** | Число дней «на смене» в месяце |

Нажмите **«Скрыть»** в заголовке столбца, чтобы убрать его. Появится панель **«Показать скрытые колонки»** — восстановление одним кликом.

Скрытие столбцов запоминается **только в этом браузере**.

### Ячейки дней

- Цвет и код соответствуют [легенде](#10-коды-отметок).
- **Выходные** по календарю подсвечены в шапке.
- Столбец **сегодняшнего дня** (если месяц на экране — текущий календарный) выделяется для ориентации.

### Редактирование (после входа)

1. **Клик** по ячейке — выпадающий список кодов или «пусто».
2. **Перетаскивание** от ячейки вправо/влево по строке — **копирование** того же кода на соседние дни (или очистка, если ячейка пустая).

Если правка запрещена вашей ролью, появится сообщение (например, сотрудник Усть-Луги не может менять график — только администратор).

### Подвал таблицы

Строка **«Всего на смене»** — суммарное число сотрудников с кодами «на объекте» по каждому дню (см. коды в разделе ниже).

### Ручное добавление сотрудника

Администратор в диалоге **«Объекты и состав»** может добавить сотрудника на **текущий открытый месяц** (ТН, ФИО, должность, объект). Такие строки помечаются как добавленные вручную и участвуют в синхронизации.

## 10. Коды отметок

| Код | Значение |
|-----|----------|
| **ОТ** | Отпуск |
| **ВХ** | Выходной |
| **Б** | Больничный |
| **БЛ** | Больничный лист |
| **ВП** | В пути (часто первый/последний день отпуска) |
| **—** | Отсутствует |
| **О** | Офис (МСК) |
| **УР** | Удалённая работа |
| **СПГ** | ВСМ (Усть-Луга), день |
| **СПГ.** | ВСМ (Усть-Луга), ночь |
| **М** | Магнит |
| **АПК** | Продовольственная программа (РМ АГРО) |
| **ГАЛС** | ООО «Галс-Девелопмент» |
| **ЗЛ** | ТК «Зеленая линия» |
| **ИНК** | Иркутская нефтяная компания |

**«На смене»** для сводки и строки «Всего на смене»: СПГ, СПГ., ИНК, УР, ГАЛС, М, АПК, ЗЛ.

Пустая ячейка в интерфейсе отображается как **«—»** (нет отметки).

## 11. Объекты и состав (настройки)

Только **администратор**: меню → **Объекты и состав**.

### Названия вкладок

Можно переименовать подписи **«Усть-Луга»** и **«Пилотные проекты»** на вкладках в шапке (для всех пользователей после синхронизации).

### Состав команд

Таблица сотрудников: для каждого ФИО выберите объект (**Усть-Луга** или **Пилотные проекты**). Это влияет на то, в какой вкладке человек отображается.

### Добавление сотрудника

Кнопка раскрывает форму: **ТН**, **ФИО**, **должность**, **объект** → **Добавить** (для **текущего открытого месяца**).

### Сброс

- **Сбросить состав** — вернуть привязку ФИО к объектам по умолчанию.
- **Сбросить названия** — вернуть стандартные названия вкладок.

**Готово** — закрыть диалог. Изменения уходят в облако с небольшой задержкой (около секунды после последней правки).

## 12. Экспорт для 1С

После входа: меню → **Экспорт для 1С**.

Скачивается файл JSON вида `workwatch-export-ГГГГ-M.json` с:

- периодом (год, месяц);
- текущей вкладкой объекта;
- активным фильтром легенды;
- списком сотрудников: ТН, ФИО, должность, дни на смене, помесячный график по дням.

Экспорт отражает **то, что видно на экране** с учётом фильтров, а не обязательно полную базу всех сотрудников.

## 13. Архив месяцев

### Что такое архив

Месяцы в группе **«Архив»** — уже завершённые периоды (с **марта** текущего года табеля) и, при наличии, данные **прошлых лет**.

В архиве:

- нельзя менять ячейки графика;
- нельзя менять расстановку по зонам;
- доступны просмотр, фильтры, сводка (по правилам данных), экспорт JSON за этот месяц.

### Будущие месяцы

Месяцы из группы **«Остаток … (пусто)»** показывают **пустой** график до наступления месяца — это защита от преждевременного отображения импортированных данных.

### Выгрузка архива за год

Полная JSON-выгрузка всех архивных месяцев года (`exportArchiveFullYear`) предусмотрена для служебного использования (консоль браузера / интеграции). В обычной работе достаточно **помесячного экспорта** из меню.

## 14. Синхронизация между устройствами

Общие данные (правки графика, состав объектов, расстановка, флаг «показать всех» и др.) хранятся в **облаке** и подтягиваются при открытии сайта.

### Что синхронизируется

- правки ячеек графика по месяцам;
- ТН и должность, изменённые вручную;
- добавленные вручную сотрудники;
- привязка ФИО к объектам и названия вкладок;
- расстановка по зонам (утро/вечер);
- «Показать всех» в легенде.

### Что остаётся только на этом устройстве

- выбранный **месяц** и **вкладка объекта**;
- **фильтр кодов** в панели «Объекты»;
- **свёрнутость панелей**;
- **скрытые столбцы** таблицы;
- **тема** (светлая/тёмная);
- **сессия входа**.

При сбое сети приложение продолжает работать с последними локальными данными; предупреждения пишутся в консоль браузера (F12), интерфейс не блокируется.

## 15. Карта BLE-меток

Откройте **«Карта»** в шапке табеля. На отдельной странице (или в полноэкранном режиме на телефоне) отображаются **метки обхода** на плане/спутнике.

### Возврат к табелю

- Кнопка с **логотипом WORK WATCH** в панели карты.
- Или ссылка **«← График»** вверху (если видна).

### Поиск и фильтры

- Поле **«№ метки»** — поиск и переход к метке.
- **Все** / **Не пройденные** — фильтр по статусу обхода; счётчики на кнопках.
- **Маршрут** — ограничить метки выбранным маршрутом (если маршруты загружены).

### Подложка карты

Переключатель **Схема / Спутник / Гибрид**. Без интернета **спутник** может не загрузиться; схема и сохранённый офлайн-пакет работают локально.

### Просмотр метки

Нажмите на метку — всплывающее окно с номером, статусом, **фотографиями** (если есть). Фото можно открыть крупно.

### Редактирование меток и зон

1. **«Редактировать»** (на узком экране — **«Правка»**).
2. **Метку**: удерживайте **около 1 секунды**, затем перетащите в новое место; отпустите — положение сохранится в черновике.
3. **Зоны** (если доступны в вашей версии): по подсказке на экране.
4. **«Сохранить»** — отправить изменения на сервер; **«Отмена»** — отменить режим правки.

В режиме правки точки на карте отображаются компактно (**20×20 px**), зона нажатия на сенсорном экране шире для удобства.

### Скачать фото (работа без интернета)

Кнопка **«Скачать фото»** (на телефоне — **«Фото»**):

1. Нужен **доступ в сеть** и успешная загрузка меток с сервера.
2. Приложение скачает метки и **сжатые фотографии** в память браузера (IndexedDB).
3. Во время загрузки отображается прогресс; можно **«Отменить скачивание»**.
4. После этого на объекте можно открывать карту и фото **без VPN/интернета** (в пределах ранее скачанного набора).

Рекомендации:

- скачивайте пакет **на Wi‑Fi**;
- на телефоне дождитесь окончания — не закрывайте вкладку;
- если фото не появились, обновите карту при наличии сети и повторите скачивание.

### Обновление карты

Кнопка **↺** (обновить) появляется при ошибке загрузки данных.

## 16. Частые вопросы

**Не вижу сотрудника в табеле.**  
Включите **«Показать всех»** в панели «Объекты» или снимите фильтр по кодам. Проверьте вкладку объекта и месяц.

**Не могу править ячейку.**  
Войдите в систему. Проверьте, что месяц не из **архива**. Сотрудники Усть-Луги (кроме админа) график не редактируют. Сотрудник пилотов меняет только **свою** строку.

**Правки не видны на другом компьютере.**  
Подождите несколько секунд после изменения. Обновите страницу. Убедитесь, что есть интернет и вы смотрите тот же месяц.

**Сводка пустая или странные цифры.**  
Сводка использует **сегодняшнюю календарную дату** и график **года из селектора месяца**. Откройте месяц, в котором заполнен график на текущий период.

**На карте нет фото офлайн.**  
Сначала выполните **«Скачать фото»** при активном интернете. Старый кэш без фото не подходит — нужна полная загрузка с сервера.

**Забыл пароль.**  
Обратитесь к администратору системы (сброс через админ-панель Supabase / повторная выдача учётной записи).
