# Подготовка к полю (синхронизация без zip)

Новая схема для iPhone и любого браузера: **не нужно** каждый раз собирать `ble-field-pack.zip` на ПК.

## Как это работает

1. На объекте **до выезда** (Wi‑Fi / VPN) откройте карту.
2. В списке **«Маршрут»** выберите **свой маршрут** (не «Все маршруты»).
3. Нажмите **«Офлайн»** (ранее «Подготовка к полю») **или** **«Скачать»** — см. ниже.
4. Система качает **только метки этого маршрута**:
   - сразу — координаты в память телефона (IndexedDB);
   - затем — фото метки и места (по одному, сжатие);
   - при повторе — только недостающие фото.
5. Можно **остановить** и продолжить позже (тот же маршрут в списке).
6. **В поле без связи** откройте карту — на карте только сохранённый маршрут **или** сохранённый HTML из «Файлы».

Другой маршрут на следующий день: выберите его в списке и снова «Офлайн» — старые фото другого маршрута удаляются из памяти.

## Скачать HTML (рекомендуется для обхода)

Кнопка **«Скачать»** в панели карты собирает **один файл `.html`**:

- снимок карты с номерами меток маршрута;
- список точек с координатами и ссылками «Открыть в картах» (`geo:`);
- встроенные фото (из памяти телефона или с сервера при сборке).

**Нужен интернет только в момент нажатия «Скачать».** В поле откройте файл из приложения «Файлы» / «Загрузки» — вкладку сайта можно закрыть и обновлять без риска.

| Действие | Как |
|----------|-----|
| Полный файл | **Маршрут** → **Скачать** → подтвердить |
| Без фото (меньше размер) | **Shift+Скачать** |

Имя файла: `ble-<маршрут>-<дата>.html`.

## Для пользователя (iPhone)

| Действие | Как |
|----------|-----|
| Подготовиться | **Маршрут** → **Офлайн** → подтвердить |
| Скачать автономный файл | **Маршрут** → **Скачать** |
| Продолжить докачку | Тот же **маршрут** в списке → **Офлайн** |
| Только координаты | Shift+клик по кнопке → пункт **4** (без фото) |
| Старый zip | Shift+клик → пункт **1** (импорт .zip) |

**Safari:** не закрывайте вкладку насовсем во время первой большой синхронизации; при обрыве просто запустите снова.

## Zip (устаревший способ)

Сборка `npm run ble-field-pack` и Release на GitHub **больше не обязательны**. Оставлены для:

- разовой раздачи архива офисом;
- устройств с очень малым объёмом памяти (редко).

Подробности старой схемы: [`ble-field-pack.md`](ble-field-pack.md).

## Технически

| Хранилище | Содержимое |
|-----------|------------|
| IndexedDB `ww-ble-field-v1` | `meta` — счётчики; `markers` — координаты; `photos` — blob по URL |
| `localStorage` `ww-ble-field-sync-state` | прогресс при обрыве |
| `localStorage` `ww-ble-field-ready` | маршрут подготовлен к офлайну (не сбрасывается при refresh) |
| `sessionStorage` `ww-ble-offline-first` | при офлайне грузить из IDB |

Источник списка меток: API → резерв `ble-map-cache.json` / Supabase.

Фото: прокси `ble-map-proxy` для Yandex Storage.

Правки координат в поле без сети по-прежнему в `localStorage` `ww-ble-offline-marker-edits`, отправка при появлении сети.
